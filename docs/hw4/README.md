## Part 3: TDD with Claude Code (15 pts)

Feature: **issue #2, referral status state machine** (PR #5). There are four red → green cycles
plus two refactors, and every `test: red` commit comes before the matching `feat: green` commit:

```
test(referrals): red — forward steps, invalid and terminal moves       (AC1–AC3)
feat(referrals): green — transition table
test(referrals): red — only the assigned referrer advances; withdraw   (AC4–AC5)
feat(referrals): green — actor permissions and withdraw/close rules
refactor(referrals): one RULES table maps each move to allowed parties
test(referrals): red — decline needs a reason; StatusChange returned   (AC6–AC7)
feat(referrals): green — decline reasons + StatusChange record
test(referrals): red — allowedTransitions                              (AC8)
feat(referrals): green — allowedTransitions derived from RULES
refactor(referrals): group test fixtures
```

Results: 70 tests passing and 100% coverage on `status-machine.ts`. Issue #1's validation schema
also went red → green → refactor, and issue #3 (partner) is a third TDD feature.
